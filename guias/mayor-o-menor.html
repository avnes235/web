Mayor o menor: reglas, pagos y probabilidades

+18 · moneda ficticiaActualizado el 23 de octubre de 2026

Casino simulado, solo para mayores de 18 años. Todas las cantidades son moneda ficticia de Casinetori: no se compra con dinero real ni se cambia por dinero o premios reales.

El juego muestra un número del 1 al 100 y eliges si el siguiente será mayor o menor. Puedes encadenar aciertos y cobrar, o perder el cobro pendiente al fallar.

Cómo se juega

  1. Elige la cantidad ficticia y comienza para ver el número actual.
  2. Compara la probabilidad y el pago de «Mayor» y «Menor». También puedes saltar un número.
  3. Tras acertar, revisa el multiplicador acumulado y decide si cobras o continúas.
  4. Si fallas antes de cobrar, se pierde la partida.

Probabilidad de cada opción

Con el número actual n, las probabilidades son:

  • Mayor: (100 − n) / 99.
  • Menor: (n − 1) / 99.

El denominador 99 describe un modelo que excluye repetir el número actual. Por ejemplo:

Número actual Mayor Menor
20 80/99 ≈ 80,81 % 19/99 ≈ 19,19 %
50 50/99 ≈ 50,51 % 49/99 ≈ 49,49 %
80 20/99 ≈ 20,20 % 79/99 ≈ 79,80 %

Pagos y cautela con el retorno

El factor por acierto descrito es 0,97 dividido por la probabilidad elegida. El multiplicador total tiene un máximo de ×1.000; las opciones demasiado fáciles no pagan.

El 97 % describe el factor de retorno por paso de esa fórmula, no demuestra por sí solo un retorno del 97 % para una cadena completa. Si cada acierto multiplica el acumulado por 0,97/probabilidad, dos pasos introducen un factor 0,97² = 94,09 %, antes de límites y excepciones. Así lo hace el juego: el multiplicador acumulado se multiplica en cada acierto. Por eso, cuantos más aciertos encadenas antes de cobrar, menor es el retorno medio (tres aciertos: 0,97³ = 91,27 %). El siguiente número nunca repite el actual: sale entre los otros 99.

Por eso esta guía no publica un RTP global cerrado ni promete que encadenar más aciertos mantenga el mismo retorno.

Qué conviene tener claro

La probabilidad de cada elección cambia con el número actual. No confundas que un lado sea muy probable con que proporcione un premio útil. Consulta el botón; no se documenta aquí un umbral exacto para las opciones sin pago.

Elige antes una cantidad de saldo ficticio que puedas perder y evita aumentarla para recuperar lo anterior. La caja fuerte separa saldo que no se utiliza en las apuestas del casino. Puedes terminar la sesión aunque una partida haya salido mal.

Los pagos descritos son los del juego base, sin bonificaciones temporales. Un multiplicador activo puede cambiar el abono: consulta su contador y sus límites. El retorno medio es una referencia matemática, no una devolución prometida en tu sesión.

Preguntas frecuentes

¿Siempre hay un 50 % de posibilidades?

No. Depende del número mostrado y de si eliges mayor o menor.

¿Puedo saltar un número?

Sí, el juego tiene esa opción.

¿El 97 % vale para cualquier cadena?

No. Cada acierto aplica un 0,97, así que una cadena de k aciertos devuelve 0,97 elevado a k: dos aciertos 94,09 %, tres 91,27 %.
